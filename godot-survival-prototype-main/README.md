# Godot Survival Prototype

A 3D isometric survival game prototype built in **Godot 4** as a personal portfolio project. It explores the systems behind a top-down survival-crafting game — player movement, skill-based combat, enemies, loot, inventory, and zone-based world design — alongside a custom **procedural 3D asset pipeline** written in Python for Blender.

> Inspired by the survival-crafting genre. Built independently to practice Godot engine architecture, GDScript, and a code-driven art workflow.

## Highlights

- **Engine:** Godot 4.x (GDScript), isometric 3D with a 45° camera
- **Gameplay systems:** player controller with movement and dodge, enemy AI, loot drops, an item database/inventory, and multiple world zones (Green/Yellow)
- **Procedural asset pipeline:** a Python + Blender toolchain (`godot_project/blender_pipeline/`) that generates low-poly models, armor/weapon meshes, and textures, then exports them to Godot as `.glb`
- **Art direction:** muted, low-poly aesthetic with clean silhouettes (see `style_guide.md`)

## Project Structure

```
godot_project/
├── scenes/            # Game scenes (player, world, zones)
├── scripts/           # GDScript: player, enemies, inventory, loot, world, utils
├── assets/            # Procedurally generated models, textures, art (self-made)
├── blender_pipeline/  # Python/Blender procedural asset generation toolchain
└── project.godot
```

## Running It

1. Install [Godot 4.x](https://godotengine.org/).
2. Open `godot_project/project.godot` in the Godot editor.
3. Press Play.

## Notes on Assets

The models, textures, and art under `assets/` are generated by the project's own Blender pipeline. **Third-party character animations are not included** in this repository: the player animation system is built to work with [Mixamo](https://www.mixamo.com/) FBX files, which you can download and drop into `assets/mixamo/` following the instructions in `scripts/utils/MixamoImporter.gd`.
